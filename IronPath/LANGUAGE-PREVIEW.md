# German translation

The language flag selects English or German and stores the preference locally. Switching language changes presentation only: account and save data, rules, map IDs, player names, codes and numeric values stay unchanged.

German coverage includes campaign missions, objectives and cinematics; core and advanced skills; equipment, bunker upgrades and medals; generated map names; battlefield labels, tower menus, abilities, upgrades, results and common command errors; tutorial and practice; authentication, friends, leaderboards and multiplayer panels; and marked static text and accessibility attributes. The Act I mission voice-over speaks in both languages. Open tutorial, confirmation, leaderboard, tower and other views are refreshed on a language change without repeating actions; cached illustrated terrain is repainted for the selected language. The static first paint (intro, sign-in, browser tab title) is translated before the Firebase SDK finishes loading, so a German player no longer meets an English login screen on a slow connection.

The translation is complete rather than a preview, so the old "Deutsch (Vorschau)" option label and the preview note are gone. Honest limits remain: unknown or unrecognized errors fall back to English, some already-displayed status messages may not refresh until their next update, and automated tests cannot establish good text fit on every device or verify real accounts, live multiplayer and recovery. Check narrow layouts and test both languages on actual devices, including a two-player session.
