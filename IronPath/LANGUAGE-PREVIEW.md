# Language switch: work in progress

This branch contains a **preview**, not a complete German localization. The selector persists only a local browser preference and does not alter account, progression, multiplayer data, player names or codes. Marked static text, the command center, major battlefield controls and field-upgrade descriptions, much of the multiplayer lobby, and the interactive tutorial can switch between English and German; the interface explicitly warns German users that text remains untranslated.

Before releasing the feature, translate and test every player-facing surface: intro, authentication and errors; campaign mission titles, briefings, objectives, radio and cutscenes; the battle HUD, towers, abilities, perks, terrain, results and notifications; skills and armory data; tutorial and practice; Friends, invitations, scores and all multiplayer setup/status/recovery flows; accessibility labels, placeholders and confirmations. Preserve state and in-progress drafts when the language changes. Test both languages, narrow layouts, text overflow, reload and storage failures, and actual two-device multiplayer. Never translate names, identifiers, saved values, or numeric game rules. Translation needs human review; avoid shipping a switch that implies the whole game is already translated.
