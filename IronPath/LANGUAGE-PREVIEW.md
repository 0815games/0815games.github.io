# German language preview

The language flag selects English or German and stores the preference locally. Switching language changes presentation only: account and save data, rules, map IDs, player names, codes and numeric values stay unchanged.

German coverage includes campaign missions, objectives and cinematics; core and advanced skills; equipment, bunker upgrades and medals; generated map names; battlefield labels, tower menus, abilities, upgrades, results and common command errors; tutorial and practice; authentication, friends, leaderboards and multiplayer panels; and marked static text and accessibility attributes. Open tutorial, confirmation, leaderboard, tower and other views are refreshed on a language change without repeating actions; cached illustrated terrain is repainted for the selected language.

This is still a preview, not a claim that every possible string has been translated: unknown or unrecognized errors fall back to English. Some already-displayed status messages may not refresh until their next update. German needs human language and terminology review. Automated tests cannot establish good text fit on every device or verify real accounts, live multiplayer and recovery. Check narrow layouts and test both languages on actual devices, including a two-player session. Keep the preview warning until those checks and any remaining gaps have been addressed.
