# Friends and multiplayer invitations

> Historical rollout note: search visibility was removed later; see `AUTOMATIC-FRIEND-SEARCH.md` for current behavior.

The host creates the existing unified multiplayer party, opens Friends from the lobby, and invites an **accepted friend**. The recipient sees an invitation while signed in, can join or decline, and joining sends the existing lobby request; the host must still approve it. The host chooses the co-op mode once the roster is ready. Search/add friends remains available inside the same Friends panel. No online presence is implied. Existing four-digit code joining and multiplayer modes remain available.

`coop-invites.complete.draft.rules.json` is a full replacement based on `friend-search.complete.draft.rules.json`, previously reported published by the user. Back up and compare the actual live rules and merge independent changes before publishing. Run and review emulator and browser tests; publish the full replacement before deploying the client. The project cannot independently inspect or publish production rules from this workspace.

Invitations are stored in the receiver's inbox, one per sender. They expire after 30 minutes for invitation-based join requests, and the rules recheck friendship, party identity, code and host before accepting the request. A closed or started party, removed friend, expired invite or reused code cannot be joined using a stale invite. The recipient can dismiss stale invitations; they are not automatically deleted. Invitations reveal the party code to the recipient, who could still share it; four-digit codes are guessable. The host must approve join requests. There is no server-side anti-spam, blocking, online indicator, trusted presence, push notification or automatic cleanup; invitations appear only while the game is open and signed in. Do not treat player-hosted results as cheat-proof.

Real-device test after deployment: two signed-in friends (both current versions), host creates party and invites; receiver accepts; host approves; choose co-op and start. Also test decline, offline/reload, expired or closed lobby, removed friend, full lobby, duplicate names, logout and mobile. Automated emulator/browser checks do not prove live multiplayer behavior.
