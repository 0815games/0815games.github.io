# INKFALL — Heroes of the Last Tower

Kooperatives Tower-Defense-Spiel mit RPG-Progression, großem Skilltree und Online-Coop für maximal zwei Spieler.

## Aktueller Stand

- Playabler Web-Prototyp
- 5 Wellen
- Pfeilturm, Frostturm, Kanone
- Kriecher, Renner, Panzerriese
- Gold, Upgrades, Wellen-Manager

## Starten

Öffne `src/index.html` direkt im Browser oder starte einen lokalen Server:

```bash
cd src
python3 -m http.server 8000
```

Dann im Browser öffnen:

http://localhost:8000

## Projektstruktur

```text
src/          Spielcode und Prototyp
docs/         Design, Balance und Tutorial
tests/        Tests und Balance-Checks
assets/       Grafiken, Audio und weitere Assets
```
