# Garage & Drive

Eigenständiger Browser-Spielprototyp für Fahrzeugdiagnose, Reparatur und Probefahrt. Das bestehende Spiel unter `game/` bleibt unverändert.

## Start

`index.html` im Browser öffnen oder über GitHub Pages unter `/game/car-workshop/` aufrufen, sofern Pages für dieses Repository eingerichtet ist.

## Aktueller Stand

Ein Auftrag, Diagnose und Reparatur als Schaltflächen, einfache 2D-Canvas-Teststrecke mit Tastatursteuerung. Noch keine echte Bauteilmontage, Fahrzeugphysik oder 3D-Grafik.

## Nächste Ausbaustufen

1. Fahrzeug- und Werkstattmodelle, 3D-Renderer und Kamera.
2. Interaktive Bauteile, Diagnosewerte und Reparaturablauf.
3. Fahrsimulation mit Fahrdynamik, Eingabegeräten und Teststrecke.
4. Grafikqualität und Performance auf Desktop und Mobilgeräten prüfen.
